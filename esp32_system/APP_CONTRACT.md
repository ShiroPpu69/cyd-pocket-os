# 应用接入约定

系统与应用保持单向边界：

1. 应用只负责自己的绘制、数据和周期任务。
2. 应用不得调用 `drawHome()`，也不需要绘制返回按钮或底部手势条。
3. 系统的 `pollTouch()` 始终先读取触摸。当触点从屏幕底边开始并向上移动
   至少 55 像素时，系统切回主屏。
4. 未构成系统手势的触摸，才交给当前应用的点击处理。
5. 离开应用时，请求应安全取消；不要跨线程销毁网络对象或强制删除持锁任务。
   后台任务完成后先发布数据快照，仅主线程、且应用在前台时才允许重绘。
6. 重网络工作需遵守系统调度器的互斥约定；Spotify 与 Deadlock 共用 TLS，
   不得并发使用。阻塞读取、驱动写入及任务退出都应有时间上限。

Dota 保留原页面布局，但联网生命周期已加固。独立模块可参考 Deadlock：
begin / loop / tap / end 接口与后台结果发布；返回主屏依旧由壳层负责。
